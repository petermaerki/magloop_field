Inductance L ... H $L = \mu_0 \cdot \frac{D}{2} \left(\ln\left(\frac{8D}{d}\right) - 2\right)$ with $\mu_0 = 4\pi \cdot 10^{-7}$ H/m. More complex formulas for multiple turns are given in the source code.

Unloaded Q0 ... $Q_0 = \frac{f}{B_{\mathrm{SWR}=2.6}}$
Damping resistance RT ... Ohm $R_T = \frac{X_L}{Q_0} = \frac{2\pi f L}{Q_0}$
Radiation resistance RR ... Ohm $R_R \approx n^2 \cdot 31171\left(\frac{A f^2}{c^2}\right)^2\left(1+\frac{1}{2}\left(\frac{\pi D f}{c}\right)^2\right)$
Loss resistance RLoss ... Ohm $R_{\mathrm{Loss}} = R_T - R_R$
Antenna efficiency η ... % $\eta = \frac{R_R}{R_T}$
Loop current Imain loop ... A $I_{\mathrm{main\ loop}} = \sqrt{\frac{P}{R_T}}$
Loop voltage Uloop ... V $U_{\mathrm{loop}} = I_{\mathrm{main\ loop}} X_L = I_{\mathrm{main\ loop}}\,2\pi f L$

Magnetic Field Calculations
Magnetic loop dipole moment: $m = n \cdot I_{\text{main loop}} \cdot A$.
For a circular loop: $m = n \cdot I_{\text{main loop}} \cdot \pi \left(\frac{D}{2}\right)^2$.
Method: exact circular-loop Biot-Savart model (elliptic integrals) in the near field, smoothly blended into a retarded dipole model in the far field (using $c$ and $f$). Multi-turn loops are treated as a single wire. Values very close to the conductor are suppressed; see the source code for details.
